# Porter logo

Existing Porter app mark exported at 1024x1024 using its original SVG geometry and light-theme colors. These files provide browser-accessible downloads for the operator's manual submission; they do not change the app.

- [PNG for upload](https://raw.githubusercontent.com/dmetagame/porter/main/media/porter-logo.png)
- [SVG vector](https://raw.githubusercontent.com/dmetagame/porter/main/media/porter-logo.svg)

In a browser, open the PNG and choose **Save image as** to download it.
